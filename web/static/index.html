Validate

      
Five levels, from it exists to it behaves.

    


    

      
Oracle and PostgreSQL do not store the same value the same way.
        Comparing raw bytes would report a failure on every numeric and every padded column of a
        perfect migration. So each row is reduced to a canonical text form on both sides
        first — trailing zeros stripped, CHAR padding trimmed, timestamps in UTC, and Oracle's
        empty-string-is-NULL given the same marker as a PostgreSQL NULL — and the same MD5 is
        computed over that. Levels 2 and 5 do not run: column types are deliberately
        different, and invalid objects and grants are Oracle catalogue concepts. What survived is
        measured by levels 3 and 4, which are the ones that answer whether the data is
        intact.
